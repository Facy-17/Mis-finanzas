¿Cómo configurar el Atajo Automático al Pagar?

Abre el formulario inmediatamente después de usar tu tarjeta o Wallet

iPhone (App "Atajos" / Shortcuts)
  1. Abre la aplicación Atajos (Shortcuts) en tu iPhone.
  2. Ve a la pestaña Automatización y toca en + (Nueva automatización).
  3. Busca y selecciona "Wallet" o "Al pagar con Apple Pay".
  4. Selecciona tu Tarjeta o Wallet y marca la opción "Ejecutar de inmediato".
  5. Agrega la acción "Abrir URL" e ingresa la URL de esta Web App añadiendo al final: ?action=add
  6. ¡Listo! Cada vez que pagues con tu Wallet o Tarjeta, aparecerá una notificación o se abrirá el formulario pidiéndote el monto y la descripción.
Android (Acceso Directo / Tasker)
  1. Abre esta página en Chrome desde tu celular.
  2. Toca los tres puntos superiores y presiona "Agregar a la pantalla principal".
  3. Opcional (Automatización): Usa la app Tasker o MacroDroid creando un evento cuando detecte la notificación de pago de tu Banco (BAC, SINPE, etc.).
  4. Configura la acción para abrir la URL de la web app con el parámetro ?action=add.
  5. El formulario se abrirá automáticamente en pantalla para registrar la compra al instante.
